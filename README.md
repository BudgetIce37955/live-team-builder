# Live Team Builder

ライブ会場・イベント等で、参加メンバーを「1組あたり◯人まで」のグループに自動で分けるブラウザツール。HTML 単体・サーバー不要・依存ライブラリゼロ。

🔗 https://budgetice37955.github.io/live-team-builder/

## 使い方

1. 参加人数を指定すると、その数だけ名前欄が自動生成されます
2. メンバーの名前を入力（空欄でも OK、自動で連番が振られます）
3. 「1組あたりの上限」を指定
4. 「グループを作る」ボタンで自動振り分け

## 振り分けルール

組数は `ceil(参加人数 ÷ 上限)`。ラウンドロビン方式で均等に配分（人数差は最大 1 人）。

| 人数 | 上限 | 結果 |
|------|------|------|
| 8 人 | 4 | 4 / 4（2 組） |
| 9 人 | 4 | 3 / 3 / 3（3 組） |
| 10 人 | 4 | 4 / 3 / 3（3 組） |

## 機能

- ランダム振り分け / 入力順振り分けの切替
- 入力内容を `localStorage` に保存（再訪時に復元）
- 結果をクリップボードにコピー
- スマートフォン対応

## ローカル実行

```sh
open index.html
```
